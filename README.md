# Применение ИИ
При выполнении данной работы был использован генеративный ИИ. Используемая модель LLM -- Google Search AI (Gemini). ИИ был применен в качестве умного поисковика/справочника для получения информации о компонентах стандартной библиотеки Python. Так как эта область применения не относится напрямую к условию задания, то используемые промпты не несут особой ценности, поэтому они опущены.
