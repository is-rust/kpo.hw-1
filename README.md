# Применение ИИ
При выполнении данного задания был использован генеративный ИИ (Google Search AI (Gemini)). ИИ применялся в качестве умного поисковика/справочника для получения информации о компонентах стандартной библиотеки Python. Описанное применение не относится напрямую к условию задания, поэтому используемые промпты опущены, т.к. они не несут особой ценности.


# Примечания
## `typing.Protocol` vs `abc.ABC`
В решении использовано оба возможных подхода описания контрактов в Python: `typing.Protocol` и `abc.ABC`. Область применения подходов была четко разграничена: `abc.ABC` использовался для описания моделей данных (в `items`), а `typing.Protocol` использовался для описания поведения (в `auditor`, `storage`, `manager`)
